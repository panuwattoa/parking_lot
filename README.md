# parking_lot
The program will manage Parking with queue for checkout slot number.

concept channel and event loop will support real world situation protect race condition and memory leak too.

## Setup
 First, install [Go]
 `https://golang.org/doc/install`

## Usage
To install all dependencies, compile and run tests:
```
$bin/setup
```

To run the program and launch the shell:
```
$ bin/parking_lot
```


To run the code so it accepts input from a file:
```
$ bin/parking_lot file_inputs.txt
```



To run the program and launch the shell:

You can run the full suite from `parking_lot` by doing

```
bin/run_functional_specs
```
